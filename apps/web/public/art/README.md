# Digipology artwork

These original raster illustrations were generated for the Digipology redesign. They are artwork, not gameplay screenshots.

- `first-deal.webp`, `dice-dash.webp`, `zone-runner.webp`: 1024 × 1536 portrait illustrations for the built-in catalog.
- `tabletop-world.webp`: 1672 × 941 wide illustration for the landing and discovery pages.

The images were encoded as WebP for delivery. Game titles remain HTML so they are legible, accessible, and independent of image generation. Community-game artwork continues to use the versioned cover API; these files do not replace that pipeline.

The marketing site contains copies of the same four files under `apps/site/public/art/` so it can deploy independently of the play application.
